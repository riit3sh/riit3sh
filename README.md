## About Me

I'm **Ritesh Subramanian (riit3sh)** — a Final Year B.Tech Computer Science student at **VIT Vellore**.

I'm building **Tolka Edge**, a unified LLM gateway that exposes an **OpenAI-compatible API** for both commercial models and self-hosted GPU deployments.

## Current Work

**Tolka Edge** — Unified LLM Gateway  

Tolka Edge provides an OpenAI-compatible API that routes requests across commercial providers and GPU-deployed models through a single interface.

Core focus areas:
- Unified API surface for commercial + self-hosted models  
- Authentication and multi-tenant key management  
- Rate limiting and traffic control  
- Routing, failover, and observability  

Built with a strong emphasis on clean architecture and production reliability.
